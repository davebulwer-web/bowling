# Lane Legends

Retro pixel-art ten pin bowling for 1 or 2 players, in the style of Oche Legends.

Open `index.html` in a browser to play. Keep the `sounds/` folder next to it for the music and name call-outs (the game still works without it, just quieter).

The `src/` folder holds the parts the page is built from: `python3 src/build.py` (run inside `src/`) joins them into `site/index.html`. `node t3.js` simulates the computer opponents' averages.
